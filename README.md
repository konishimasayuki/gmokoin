# FXスキャル・ペーパー

GMOコインのPublic API（認証不要）のリアル価格を使い、仮想売買（ペーパートレード）するスキャルピングBotです。外国為替FX（6銘柄）と暗号資産の取引所レバレッジ（BTC・ETH・XRP・BCH・LTC、取引手数料無料）に対応しています。仮想通貨の値幅は bp（価格の0.01%）で扱います。実際の注文は一切出しません。

## 仕組み

画面は「ホーム／AI頭脳／成績／設定」の4タブです。

**AIチーム（Claude）**
- **ファンダ担当**：取引日（6:00区切り）ごとに1回、web検索で今日・今週の重要指標とニュースを集め、「確認済み／未確認／誇張の可能性」に仕分けます。
- **議長**：15分ごとに、水平線マップ・ブリーフ・1時間足・5分足を統合して方針（上昇トレンド／下降トレンド／レンジ／見送り、確信度）を決めます。
- **反論役**：議長の方針の弱点を突き、「同意／弱め（確信度を下げる）／却下」を出します。確信度45%未満は見送り。
- **反省会担当**：日次・週次で取引を分析し、負けパターンと設定の変更案（最大3つ）を出します。変更は「採用」ボタンで人が承認したときだけ反映。

**プログラム（固定ルール）**
- **水平線マップ**：週足（過去2年）・日足（過去3か月）の高値・安値から水平線と反発回数を計算。利確までの間に強い線があればエントリーしません。
- **売買**：1分足のEMA9/21・RSI7・ボリンジャーバンド・ATRで、上昇なら押し目買い、下降なら戻り売り、レンジならバンド端の逆張り。
- **安全装置**：取引時間帯（東京・ロンドン・NY、早朝は常に停止）、5分足の向きフィルター、建値ストップ、連敗ストップ、スプレッド・ATR上下限、指標前後の停止、日次損失上限、取引回数上限、クールダウン。
- **数量**：固定、または「資金の◯%のリスク」で自動計算。
- **設定ロック**：本日マイナス・2連敗以上・連敗ストップ中は、リスクを増やす設定変更を受け付けません。
- **AIおまかせ（自動選定）**：1日1回、全11銘柄（FX6・仮想通貨5）×約580通りの設定を過去90日で試し、5段階の検証（①前半60日で選び後半30日でも勝てたか ②ランダムな40週で7割以上が勝ち週か ③1000回の引き直しでマイナス確率25%以下か ④スプレッド2倍＋約定ズレでも負けないか ⑤設定を少しズラしても勝てるか）をすべて通ったものだけを採用。合格がなければ新規エントリーを止めます。銘柄ごとに1リクエストで検証するため、タイムアウトしにくい構成です。
- **バックテスト**：過去の1分足で今の設定を再生（相場判定は1時間足の機械判定で代用）。PF・最大ドローダウン・時間帯別成績を表示。

## ポートフォリオ運用

AIおまかせでは、5段階の検証に合格した銘柄を最大5銘柄（設定で変更可）まで同時に監視し、条件がそろった銘柄から入ります。
- 各銘柄は、その銘柄で検証に合格した設定（足・時間帯・利確/損切り幅など）で動きます。
- 同時に持つポジション数の上限（既定3）と、同じ通貨を同じ向きに持つ数の上限（既定2。円売りが重なりすぎない）を守ります。
- 候補が重なったときは、AIの確信度が高い銘柄から入ります。
- 議長・反論役は全銘柄をまとめて1回ずつ判定するので、銘柄が増えてもClaudeの呼び出し回数は増えません。
- 損失上限・連敗ストップは口座全体で管理します。

## 動作の前提

画面を開いている間、ブラウザが数秒ごとに `/api/tick` を呼んで動きます。画面を閉じていた間の損切り・利確・時間切れは、再開時に1分足の高値・安値で判定します（同じ足で両方に触れた場合は損切り扱い）。

## セットアップ

1. このリポジトリをVercelにインポートします（Framework: Vite）。
2. Vercel の Storage から Upstash Redis を接続します（`KV_REST_API_URL` / `KV_REST_API_TOKEN`、または `UPSTASH_REDIS_REST_URL` / `UPSTASH_REDIS_REST_TOKEN` が自動で入ります）。
3. 環境変数を追加します。

| 変数 | 内容 |
| --- | --- |
| `ANTHROPIC_API_KEY` | Claude APIキー |
| `APP_PASSCODE` | ログイン用パスコード（任意の文字列） |
| `CLAUDE_MODEL` | 任意。既定は `claude-sonnet-5-5` |
| `ANTHROPIC_WORKSPACE_ID` | 任意。ワークスペースに紐づかないAPIキーを使う場合だけ、使うワークスペースのIDを指定 |

4. 再デプロイし、パスコードでログインして「停止中」ボタンを押すと稼働します。

関数は `vercel.json` で東京リージョン（hnd1）に固定しています。

## API

| パス | 内容 |
| --- | --- |
| `POST /api/tick` | 価格取得・決済判定・エントリー判定。`?full=1` で履歴とログも返す |
| `POST /api/regime` | Claudeの相場判定（`{"force":true}` で即時） |
| `GET/POST /api/config` | 設定の取得・保存 |
| `POST /api/close` | 手動決済 |
| `POST /api/reset` | ペーパー口座リセット（`{"confirm":"RESET"}`） |
| `GET /api/trades` | 取引履歴（最大200件） |
| `POST /api/brief` | ファンダ担当のブリーフ作成 |
| `GET/POST /api/levels` | 水平線マップの取得・再計算 |
| `GET/POST /api/report` | レポート一覧・作成（`{"kind":"daily"|"weekly"}`） |
| `GET/POST /api/backtest` | 前回結果・実行（`{"days":5}`） |
| `GET/POST /api/optimize` | 自動選定。`{"action":"symbol","symbol":"USD_JPY"}` で1銘柄を検証、`{"action":"finalize","apply":true}` で採用を決定 |
| `GET/POST/DELETE /api/login` | ログイン状態・ログイン・ログアウト |

## Redisキー

すべて `fxbot:` プレフィックス。取引は `fxbot:trade:<id>` に1件ずつ保存し、`fxbot:trade_ids` のリストから MGET でまとめて取得します。

## 本番（実弾）化について

GMOコインのPrivate API（APIキー＋HMAC署名）で発注に置き換える想定です。その際は、画面を開いている間だけ動く今の方式ではなく、常駐ワーカー（VPS等）に移して24時間ポジションを管理してください。
